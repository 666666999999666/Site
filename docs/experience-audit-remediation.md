# 网站体验审查：代码修复与验收说明

日期：2026-10-20。基线：`d63a2c9`。本批修改代码与合成测试数据，没有修改线上文章、上传文件或生产数据库，也没有执行发布。最终运行时代码冻结为 `d725a05`，其后的本说明更新不改变运行时代码。

## 实现

- 编辑器：替换会把缩放比例写入 alt 的默认图片节点；alt、图注与展示宽度分别保存。Markdown 使用 `![alt](url "图注 {qz-width=600}")`，仅末尾合法的标记解释为宽度。旧的数字 alt 保持原样，需作者逐图校对。图片设置、拖动、取消、撤销/重做与中文输入组合键有回归用例。
- 阅读：原生模态 dialog 隔离背景，关闭恢复焦点；可在适应屏幕/原尺寸之间切换，双向滚动、键盘移动、图集导航和原图入口均有对应实现。无目录的文章保持可读行宽并居中。
- 代码：复制值来自 Markdown AST 的原始 code.value，不取高亮后的 HTML，也不暗中替换 NBSP 或零宽字符。成功与失败分别反馈。显示换行处理不再误改代码块中的 `<br>`。
- 内容输出：已有 excerpt 为摘要唯一人工来源，卡片、RSS、SEO、结构化数据和预览复用同一安全降级。纯图旧数据不会再生成数字 alt 摘要；缺少文字时明确提示暂无摘要，不虚构文章收获。
- 轻量阅读信息：Post 新增 nullable `contentFormat`、`readHint`；旧数据无需回填即可读取。纯图可自动显示图片数量，作者可以提供阅读提示。
- 编辑器基线：外部替换后以实际 dispatch 完成（含内部尾段落）的文档为基线，避免自动多出换行被误当作者修改。单图切换/取消原文逐字回归，六图上传后复核提示与正文指纹保持一致。
- 上传同步：浏览器诊断捕获上传 URL 后被旧 base64 序列化回灌的竞争。异步上传后同步提交受控编辑器替换，再显示复核；5 次重复测试无回退，提示稳定且确认后保存成功。实际 PostForm 的 API 保存、读取、重开、预览均保留 600px/alt/图注（API 为 mock，不冒充生产 DB）。
- 发布检查：代码不可见字符、疑似占位 alt、纯图无摘要给出原文位置和上下文。草稿保存不受阻；发布相关内容变化时需要修正或显式确认，正文不会被自动清洗。确认与当前内容绑定，修改后失效。未改变正文/标题/摘要的已发布 metadata 保存无需再次确认。
- 发现：列表由服务端搜索，仅向卡片传最小 DTO；搜索上下文是限长的纯文本，标题及片段匹配安全高亮。清空搜索保留分类，重置全部另有入口；零结果与未发布文章的空站区分。
- 组织：系列统一显式排序与可见编号/开始入口；非系列前后篇明确按发布时间。相关推荐只包含有系列/分类/标签依据的文章，无依据时明确标为最新文章。标签拆分明确分隔列表，保留技术语法中的逗号；旧组合标签 URL 作为聚合入口继续可用，不自动合并 Harness 等语义别名。
- 首页与关于页：按作者确认将学习记录与 Agent 工程实践并重，公开计算机相关硕士在读、关注 Agent/Python 后端；只修改静态文案，不编造学校、经历或项目贡献。生产 CMS Setting 覆盖值仍需单独备份与修改。
- 草稿兼容：新增 nullable 元数据字段后，旧版无 owner 和有 owner 的本地草稿均补默认值再验证；不因缺少新字段丢弃可恢复正文。
- 发现与辅助导航：sitemap 强制请求时动态生成，排除草稿/空系列，系列 lastmod 包含公开文章更新时间；每个 canonical 页面保留 RSS alternate；RSS 不长缓存已撤回文章；跳过导航入口聚焦到 main。

## 静态图片版本

生产机依然不运行 Sharp/libvips，也不开启 `/_next/image`。以下工具只在开发机/受控离线环境生成派生文件：

```sh
node --import tsx scripts/prepare-image-variants.ts --input /path/to/originals --output /path/to/new-output-directory
```

输出目录必须不存在且与输入不同。原图不改写；工具生成 640/960/1440/1920 中不超过原尺寸且文件更小的 WebP，以及每图的 `.qz-image.json`。动态图、含方向标记的图保留原图并报告，不擅自转静态。报告记录输入 SHA256、像素和文件字节，不等于浏览器网络收益。

授权发布资源时，先按报告核对原图 hash；只将对应 WebP 与 sidecar 放在同一上传目录，不把报告当正文资源。服务端仅读取文章引用图片的有限、严格校验 metadata；缺少/损坏 manifest 或文件即回退原图。原图尺寸预留比例，作者展示宽度单独控制，灯箱始终打开原图。清理器保护仍被文章/项目/系列引用的原图派生集合。实际历史图片尚未生成/上传，故 Q05 不能据此宣布线上性能改善。
