# ADR 0001：网站未来的 Agent 接入边界

- 状态：提议，尚未实施
- 日期：2026-08-24

## 背景

QZ Site 当前是个人博客、项目证据门户，以及面向外部 Agent 的受控 MCP Tool Server。它不是已经实现 LLM、RAG、规划或记忆的 Agent。本 ADR 只记录未来可能的接入方向，不新增聊天入口、Agent API、后台任务或运行时依赖，也不改变现有 MCP 行为。

## 当前决定

当前阶段只在网站发布静态架构说明、脱敏截图、测试结果和可复现步骤。若需要展示一次运行过程，优先发布离线生成、经过脱敏的事件流或任务回放。网站不托管完整远程 Coding Agent，也不向匿名访客开放通用工具调用。

KamaClaude 未来可以作为 MCP Client 使用 QZ Site 已存在的受控工具，但必须沿用服务器端既有授权范围。人工批准只能在已存在的工具、已授权根目录和操作系统沙箱内批准一次调用，不能新增工具、启用 host fallback、扩大文件根目录、放宽网络出口或越过沙箱。

## 升级到受限交互演示的前置条件

只有同时满足以下条件，才评估受限交互演示：

1. 工具使用显式白名单，并对每个参数做服务端结构与业务校验。
2. 每个访客使用一次性、可销毁的隔离工作区；操作系统级沙箱已通过逃逸测试。
3. 默认无网络出口；确需联网时只允许固定域名、方法和响应大小。
4. 具备用户鉴权、速率限制、并发限制、超时、Token 上限和单次费用上限。
5. 输入、输出、事件和 Trace 在持久化前完成敏感信息脱敏。
6. 具备审计、强制终止、熔断和无需重新部署的紧急关闭开关。
7. Agent 崩溃、浏览器断开、模型超时或服务重启后，都能回收进程、临时文件和租约。
8. 已有独立威胁模型、滥用测试、成本告警和至少两周的受控试运行数据。

## 明确排除

当前不公开完整 bash、任意文件读写、任意 MCP Server、生产数据库、管理员 Session、服务器宿主目录或无限制网络出口。不把“需要人工点击批准”视为隔离措施，也不把前端隐藏按钮视为权限控制。

## 重新评审触发条件

当静态证据与脱敏回放已经不能满足真实招聘展示或明确用户需求，并且上述安全与运维前置条件可以被测试证据验证时，重新评审此决定。在此之前，Agent 展示与网站运行面保持分离。
